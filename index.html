Công cụ Copy Prompt chuyển đổi dữ liệu LotusLMS

Sử dụng prompt chuẩn dưới đây để hướng dẫn ChatGPT (hoặc các AI khác) chuyển đổi file Word/PDF thành định dạng JSON tương thích với LotusLMS.

Hướng dẫn thực hiện:

  1. Nhấn nút "Copy Prompt" ở góc phải bên dưới khu vực hiển thị prompt.
  2. Mở ChatGPT.
  3. Dán (Paste) đoạn prompt vừa copy vào khung chat và gửi đi để thiết lập hướng dẫn cho AI.
  4. Sau khi AI phản hồi đã hiểu, hãy đính kèm file (PDF/Word/Ảnh) đề thi/tài liệu của bạn lên và yêu cầu chuyển đổi.
  5. Tải file JSON kết quả do AI tạo ra và sử dụng công cụ tải lên ở bên dưới.
